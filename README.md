# RiverData
The goal of this app is very simple. Graph river depth on your pebble!

The depth data is grabbed from the USGS website through their API. Then, that data is sent to the watch and graphed on the screen. The y axis is automatically acaled based on the data and screen size. The x-axis is fixed at the last week of data.

River Monitoring location can be changed in the app's settings page. Look up Monitoring location IDs through the USGS website: https://waterdata.usgs.gov/

DISCLAIMER : This app contains code generated by Gemini. The vast majority of which is in the index.js file.
